写文章只要会这几样就够了。这篇既是速查表，也是渲染测试。

## 标题

从 `##` 开始用到 `####`，因为 `#` 已经留给文章标题了。标题会自动生成目录和锚点链接，鼠标移上去能看到 `#`。

## 强调

`**粗体**` 显示为 **粗体**，`*斜体*` 显示为 *斜体*，`~~删除线~~` 显示为 ~~删除线~~。

反引号包住的内容会变成等宽的 `行内代码`。

## 列表

无序列表用 `-` 或 `*`：

- 第一项
- 第二项，稍微长一点也没关系，同一段里换行仍然属于这一项
- 第三项

有序列表用数字，数字写几都行，渲染时按顺序排：

1. 先列提纲
2. 再填内容
3. 最后通读一遍

## 引用

> 写作不是记录已经想清楚的东西，而是把想不清楚的东西想清楚。
>
> 引用里可以有多段，也可以放其他元素：
>
> - 列表
> - 以及 `代码`

## 表格

| 项目 | 静态 | 动态 |
| --- | --- | --- |
| 服务器 | 不需要 | 需要 |
| 数据库 | 没有 | 有 |
| 被攻击面 | 极小 | 需要持续打补丁 |
| 发布方式 | 构建后上传 | 后台点发布 |

## 代码

行内写法是 `node build.js`。

多行用三个反引号，后面跟语言名：

```javascript
function greet(name) {
  const message = `你好，${name}！`;
  return message;
}

console.log(greet('世界'));
```

```bash
node build.js && node serve.js
```

```html
<p class="meta">构建时间：2026-10-20</p>
```

## 链接与图片

链接：`[文字](https://example.com)` → [示例链接](https://example.com)。

图片：`![说明](/assets/photo.jpg)`。图片放 `public/assets/` 下（注意每次构建会清空 `public/`，所以原图要放在别处再拷进去）。

## 几条写作约定

- 一个二级标题讲一件事，段落别超过十行
- 代码块标上语言，读者看起来更清楚
- 表格只放真正需要对比的内容，能写成句子就写成句子

写作的时候不用管这些，写完再回头看一遍就行。
